# Iris Flower Classification using Naïve Bayes

## Overview
This project implements a **Naïve Bayes classifier** on the **Iris dataset** to classify flowers into three species:  
- **Setosa**  
- **Versicolor**  
- **Virginica**  

The dataset consists of **sepal length, sepal width, petal length, and petal width**, which are used as features for classification.

## Dataset  
The dataset used is **Iris.csv**, which contains 150 samples, each with four numerical features and one categorical target label.

### **Dataset Columns:**
- **Sepal Length (cm)**
- **Sepal Width (cm)**
- **Petal Length (cm)**
- **Petal Width (cm)**
- **Species** (Target Variable: Setosa, Versicolor, Virginica)

## Implementation  
The project is implemented using:
- **Python** (Jupyter Notebook)
- **Scikit-Learn** for machine learning
- **Pandas & NumPy** for data handling
- **Matplotlib & Seaborn** for visualization

## Files in Repository  
- **Iris.csv** → The dataset  
- **iris_classifier_naive_baiyes.ipynb** → Jupyter Notebook with data preprocessing, model training, and evaluation.
